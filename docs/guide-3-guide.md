# 自托管 AI 伙伴 · 第三阶段手册：从"队友"到"能带你通关的向导"

草稿 · 2026-10-23 · 接第二阶段（docs/guide-2-teammate.md）之后

第二阶段做完的伙伴是**队友**：你给目标，它自己拆步骤、干活、卡住了回来问。这本手册让它变成**向导**：它知道"通关"是一条什么路、我们现在走到哪、下一步该干什么，会主动提议并带你去做，最后和你一起打掉末影龙。

这是三本里最不确定的一本：战斗、下界、末地的每一样都没有现成的轮子。所以它故意写得比第二阶段粗一些，任务单只定目标和验收，具体做法留给做到那一步时再定。**凡是写"待定"的地方，做之前先补一张细则给我审。**

## 读之前：向导和队友差在哪

队友被动等目标；向导自己有目标。要做到这一点，缺四样东西：

| 缺的东西 | 是什么 | 放在哪一层 |
| --- | --- | --- |
| 通关地图 | "原版从空手到打龙要经过哪些阶段、每个阶段的目标是什么、需要什么" | 知识层：`knowledge/progression.yaml` |
| 进度感 | "我们现在在哪个阶段、缺什么、上次做到哪" | 决策层 + 记忆：新表 progress、world_facts |
| 主动性 | 没人说话时它也会想"现在该干什么"，并且会开口 | 决策层：空闲循环 |
| 自保和战斗 | 不自保就活不到下界；要带你打龙就得会打 | 执行层：全新的一块，Baritone 不管 |

**铁规矩在第二阶段的基础上加三条**：

4. **它提议，你决定**：任何会改变存档状态的大动作（点燃传送门、进要塞、放末影之眼、打龙）它只提议，你说"去"才动。
5. **战斗只对敌对生物**：永远不攻击玩家、村民、宠物、任何和平生物；怪物也只在它或你被攻击、或你明确说"打"时才动手。
6. **离你不超过 32 格**：带路时它走在前面，但你落后超过 32 格它就停下等你；下界和末地这个数缩到 16。

## 做完的标准

| 编号 | 你能做到的事 | 怎么算通过 |
| --- | --- | --- |
| A | 新存档开局，你问"我们该干什么" | 它说出符合当前阶段的下一步，并解释为什么（"还没有铁，先找个洞口挖煤和铁"） |
| B | 你什么都不说，站着 | 它在 1 分钟内主动提议一件事；天黑了会提醒回家；你拒绝了它不再纠缠 |
| C | "带我去附近的洞口 / 村庄 / 水边" | 它走在前面带路，你落后它就等，到了说一句 |
| D | 晚上你们在野外，僵尸来了 | 它挡在你身前打僵尸，不打村民不打你 |
| E | "我们去下界" | 它检查材料（黑曜石、火、食物、武器），缺什么说清，齐了带你建门、点燃（你确认后） |
| F | 下界里"找要塞 / 找烈焰人" | 带路、协助打烈焰人、收集烈焰棒，你落后就等 |
| G | "找末地传送门" | 它用末影之眼带路（你确认每次投掷），找到要塞和传送门 |
| H | 打龙 | 它会打末影水晶（远程）和龙（近战），会躲龙息，你死了它继续，它死了会回来 |
| I | 整个过程它知道进度 | 任何时候问"我们到哪了"都能准确说出阶段和缺的东西 |
| J | 第一、二阶段的标准全部仍通过 | 回归 |

## 第 1 步 · 通关地图和进度感（知识层 + 后台）

### 1.1 任务单 16 · 通关地图（knowledge/progression.yaml）

```text
任务：写一份原版生存的阶段地图，纯数据，后台读它，不写进代码。
1. 阶段（有序）：开局（木头、工作台、木镐）→ 石器（原石、石镐、熔炉、床、火把）→ 吃饱（食物来源）→ 铁器（煤、铁、铁镐铁剑、盾、桶）→
   钻石（钻石镐、附魔台可选）→ 下界准备（黑曜石 10、打火石、食物、弓）→ 下界（要塞、烈焰棒 ≥ 7、末影珍珠 ≥ 12）→
   末地准备（末影之眼 ≥ 12、床或药水、箭、南瓜头可选）→ 末地（找传送门、打龙）。
2. 每个阶段：name、目标清单（物品 + 数量）、推荐动作（用第二阶段的命令名）、常见风险（"下界别在岩浆边挖"）、一句给主人的说明。
3. 阶段完成的判定写成可机读的条件（背包或世界事实满足什么），后台据此自动推进，不靠模型猜。
验收：单元测试：给一组背包和事实，能算出当前阶段和缺的东西；三个人工 review 的例子（开局、铁器、下界准备）结果和老玩家判断一致。
```

### 1.2 任务单 17 · 进度和世界事实（server/memory + brain）

```text
任务：
1. 新表 progress(stage, reached_ts, notes)；new 表 world_facts(kind, name, dim, pos, ts, source)：kind ∈ home / bed / portal_overworld / portal_nether / fortress / stronghold / end_portal / village / cave / water / mine_site / danger。
2. 事实来源：主人说的（"这里是家"）、它自己走到的（第一次见到村庄、传送门）、任务结果（挖矿的地点）；模组加一个"看见了什么"的事件：
   视野内出现村庄的钟 / 传送门框 / 下界要塞砖等地标方块时发 event landmark。
3. Brain 的上下文加三段：当前阶段和缺的东西；最近的世界事实（最近 10 条，按距离排序）；今天做了什么。全部结构化、短。
4. "我们到哪了"这类话有专门工具 report_progress，不让模型自由发挥，答案从 progress 表和地图算出来。
验收：I 标准；问 10 次"我们到哪了"和人工判断一致 10 次。
```

### 1.3 任务单 18 · 空闲循环和主动提议（server/brain）

```text
任务：
1. 空闲 = 没有计划在跑、主人在服、距离上次说话 ≥ 60 秒。空闲时每 60 秒跑一次"想一想"：输入是阶段、缺的东西、时间、天气、附近事实、主人的位置和状态；
   输出三选一：建议（一句话 + 对应的计划草稿）、提醒（天黑、饿、血低）、什么都不说。
2. 主人拒绝了一个建议（"不要""等会"）→ 同一建议 10 分钟内不再提；连续被拒 3 次 → 之后只在被问时说。
3. 建议被接受（"好""去吧"）→ 变成第二阶段的 Plan 执行。
4. 提醒类不需要确认但有节流：同一类 5 分钟最多一次。
5. 所有主动说的话在网页里标成"它主动说的"，和回答区分开，便于你判断它是不是太啰嗦。
验收：B 标准；连续观察 30 分钟，主动发言 ≤ 6 次，且没有一次是在你正在打字或刚拒绝之后。
```

## 第 2 步 · 自保与战斗（执行层，全新）

**这一步在做什么**。Baritone 只管走路和挖，不管打架。要自己写：选目标、靠近、挥剑、后撤、吃东西、举盾。这是整个三阶段里风险最高的一块（打错对象、追着怪跑丢、掉岩浆）。所以从"只自保"开始，再到"保护主人"，最后才是"主动攻击"。每一级都要能用开关关掉。

### 2.1 任务单 19 · 自保（self_defense）

```text
任务：
1. 威胁感知：每 tick 扫 8 格内的敌对生物（Monster 子类，排除和平和中立未激怒的），记最近的一个及其距离、方向。
2. 规则（不经过模型，模组里写死）：被攻击或敌对 ≤ 3 格 → 面向它、攻击（用 gameMode.attack，遵守攻击冷却），血量 ≤ 8 且有盾 → 举盾后撤；
   血量 ≤ 6 → 吃金苹果/食物并后撤到主人身边或向出生点跑；骷髅等远程 → 走 Z 字接近或躲到障碍后（先做简单版：接近）。
3. 禁区：绝不攻击 Player、Villager、Animal、Tamable；苦力怕只躲不打（第一版）。
4. 战斗期间当前 Plan 暂停，结束后恢复；战斗超过 30 秒或血量持续下降 → 放弃战斗，跑向主人，发 event danger。
5. 所有战斗事件发 event combat（目标种类、结果、耗时），日志不含坐标以外的原文。
验收：D 标准的前半（自己能活）；20 次夜晚野外测试死亡 ≤ 3 次；0 次攻击错对象。
```

### 2.2 任务单 20 · 保护主人与协同（protect / fight）

```text
任务：
1. protect 模式（跟随的升级）：跟随时威胁感知范围以主人为中心 8 格；敌对接近主人 → 挡到主人与怪之间并攻击。
2. fight(target_kind) 命令：主人明确说"打"时才有；只打指定种类，打完回来。
3. 远程：有弓和箭时对 6 格外的目标用弓（充能 ≥ 1 秒再放）；这是末影水晶和烈焰人需要的。
4. 协同规则：主人在打的目标它不抢（避免误伤和经验争抢）；主人血低它上前顶住。
验收：D 标准全部；F 的烈焰人部分。
```

## 第 3 步 · 带路、下界、末地

### 3.1 任务单 21 · 带路（lead）

```text
任务：
1. lead(place / coordinates)：它走在前面，每走 8 格看一次主人距离；主人 > 32 格（下界/末地 16）→ 停下等，等的时候面向主人；主人靠近再走。
2. 路上遇到危险（岩浆、悬崖、夜晚敌对）→ 停下说一句，等主人回应。
3. 到达后说一句并把这个地点记成事实（如果是地标）。
验收：C 标准。
```

### 3.2 任务单 22 · 下界（nether）

```text
任务：
1. 建门：检查黑曜石 ≥ 10、打火石；放置 4×5 门框（这是第一次允许"按图纸放方块"，仅限这一张图纸）；点燃前必须主人确认（铁规矩 4）。
2. 两边传送门坐标进 world_facts；传送后发 event dim_change。
3. 下界导航：Baritone 在下界的参数（避免岩浆：avoidance 相关设置待定）；每走 16 格确认主人跟上。
4. 找要塞：探索（IExploreProcess）+ 地标事件（下界砖）；找到记事实。
5. 烈焰人：fight(blaze) + 收集烈焰棒；珍珠：优先和平方式（第一版不杀末影人，提示主人去交易或白天捡）。
验收：E、F。
```

### 3.3 任务单 23 · 末地（end）

```text
任务：
1. 末影之眼找要塞：主人投掷，它读眼的飞行方向（ClientboundAddEntity + 轨迹）给出方位和大致距离，带路；三角定位两次后给出坐标。
2. 要塞内找传送门房：探索 + 地标（末地传送门框）；补眼由主人放（铁规矩 4）。
3. 打龙：先打水晶（有弓用弓，没弓爬塔待定）；龙俯冲时近战；龙息粒子区域内不停留；血低先撤到基岩柱后面吃东西。
4. 它死了：末地重生在出生点，自动回来（需要重新进传送门，路线来自 world_facts）。
验收：H。这条做之前单独写细则给我审，包括"做不到就只当辅助"的退路。
```

## 第 4 步 · 验收

| 场景 | 通过 |
| --- | --- |
| 新存档从头到进下界 | 全程它提议、你决定，没有一次要你教它下一步 |
| 夜晚野外 20 分钟 | 它活着，你活着，没打错对象 |
| 下界找到要塞并拿到 7 根烈焰棒 | 它带路、协同 |
| 找到末地传送门 | 眼由你投，方向由它算 |
| 打龙 | 龙死；或者它清楚说明了自己做不到哪一步 |
| 第一、二阶段全部标准 | 回归 |

记到小本子：每个阶段耗时、它主动发言次数和被拒次数、战斗死亡次数、打龙用时。

## 出问题时查这里

| 现象 | 先看 | 常见原因 |
| --- | --- | --- |
| 它太啰嗦 | 空闲循环的节流日志 | 60 秒间隔或拒绝记忆没生效 |
| 它追着怪跑没了 | combat 事件的耗时 | 30 秒放弃没生效；或"跑向主人"目标用错 |
| 它打了村民 | 目标过滤 | Monster 判断写错，必须用类型白名单不是黑名单 |
| 阶段算错 | progression.yaml 的判定条件 | 条件漏了某个等价物品（石镐 vs 其他镐） |
